# Deliverables

Where FABRIC run outputs land — versioned (charter §5: "version every design, config, runbook").
Scratch goes under `deliverables/_scratch/` (gitignored); everything else is tracked.

## Worked example
- **`example-acme-sp/`** — a complete worked engagement that threads one problem through **every
  phase**, with connected artifacts (the LLD's addressing shows up in the config; the validator runs on
  that config; the BoM quantities trace to the design). It demonstrates the whole fabric end-to-end and
  doubles as a reference for the shape of each deliverable.
